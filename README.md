# 简易旋转倒立摆 C题 —— 基本要求(1) 实现

> 赛题：2013 全国大学生电子设计竞赛 本科组 C题《简易旋转倒立摆及控制装置》
> 已实现：**基本要求（1）** —— 摆杆从下垂(0°)起，靠摆臂往复"泵摆"使摆角达到/超过 **±60°**；>30s 判失败。
> 平台：STM32F103C8 + 标准外设库（与桌面"电赛基础资料"教程同风格，可直接并入其工程）

## 一、控制原理

基本要求(1) 不是稳倒立，而是**荡秋千式把摆杆泵到 ±60°**。

> ⚠️ 关键教训（2026-07-14 坐实）：参考笔记里的**纯 Spong 能量法** `τ=K·(E_target−E)·sign(θ̇·cosθ)`
> 是"扭矩指令"，在**真实 Furuta 二自由度耦合**下，耦合项会把方波扭矩整流成净转动，
> 臂**单方向狂转**（仿真证：臂累计 3400~4800°）——这正是硬件上"一直在狂转"的真凶。
> 且摆幅一旦被泵过 90°，cosθ 翻号 → 更失控。**所以原样抄参考 = 狂转。**

> ⚠️ 方案 H2 上板实测**仍像"狂转"**（用户2026-07-14 反馈）。二次根因：H2 用**盲定时**驱动臂（每 550ms 翻向），
> 根本**不看摆杆在哪**——这不是荡秋千式泵能，臂只在自己频率上大幅来回，视觉上就是"狂甩/像转圈"；
> 且标定符号一旦反，其"占空比积分保险"作用在**指令占空比**上而非真实臂运动，救不回。
>
> 故彻底弃用盲定时/能量法，改学 **CSDN《双环PID实现倒立摆》博客的"启摆"真经**——**相位锁定 + 硬制动**：

本工程 `Swing.c` 采用**方案 I（相位锁定双踢泵能 + 硬短路制动，TurningPointPump）**：
移植博客"启摆"状态机（在摆杆最高点给有界双踢，像荡秋千在最高点加力），并补三道结构保险根治"狂转"。

```
1) 相位锁定检测: 每 ~40ms 采 3 次摆杆角 θ(0°=下垂,+逆时针,±180°=倒立),
   判定"最高点"(中间那次是局部极值 且 |θ|≥TURN_THRESH). 【仅在最高点触发一次泵能】.
2) 有界双踢 + 硬制动: 命中最高点 ->
     KICK1(朝偏转侧, PUMP_PWM) -> BRAKE1(硬短路制动, 卸臂动量) ->
     KICK2(反向) -> BRAKE2(硬制动) -> 回 DETECT.
   双踢净位移≈0; 臂在两次制动间被【物理锁死】, 结构上【绝不可能转圈】.
3) 去掉脆弱的启动标定(真凶来源). 方向靠【自动学习】: s_pumpSign 初值 +1,
   若连续 SHRINK_CYCLES 个摆动周期峰值不增(且幅度>AMP_LEARN_DEG) -> 自动翻转.
   摆杆起不来会自动纠正, 用户无需手动翻符号.
```

- **三重保险, 臂结构上必往复、绝不转圈**：① 硬短路制动(`Motor_Brake`)在 DETECT 与两次踢之间把臂**物理锁死**, 不能累积转角；② 有界双踢净位移≈0, 臂永远回原点附近；③ 臂角硬越界 `|臂角|>ARM_LIMIT_DEG` → 强制制动回 DETECT(双保险, 有刹车本不会触发).
- **电机方向铁律(江协原版)** `Motor_SetSpeed(+)`⇒PB12=0/PB13=1；`Motor_Brake()`⇒IN1=IN2=H,PWM满(硬短路制动, 几十ms卸掉臂动量). **无需启动标定**, 泵方向由自动学习得到(屏 `Sign:±1` 可看).
- **泵能有效性**：双踢在摆杆最高点加力，相位正确时每个周期都往摆杆灌能量 → 摆幅单调增大到 ±60°(任务1达标). 若初始相位反了(灌成泄能), 自动学习会在幅度>15°后翻转纠正.

成功判据：`|θ| ≥ 60°` → 记 `g_ok` 并**硬制动停机保持**（屏显 OK60，干净交卷，符合赛题"尽快达到±60°"）；`|θ|≥150°` 记 `g_looped`(竖直圆周, 说明已泵很高)；运行 `> 30s` 仍未到 → 判失败（FAIL）.

## 二、工程装配（已就绪）

本目录**已是可直接打开的完整 Keil 工程**，双击 `C题倒立摆.uvprojx` 即可在 Keil uVision5 打开，**无需再从教程复制脚手架**：

- `Start/`    ：启动文件 `startup_stm32f10x_md.s` + CMSIS（F103C8 属 MD 中等容量，**ST 官方芯片 SDK**）
- `Library/`  ：标准外设库（**ST 官方芯片 SDK**，见下方"代码来源说明"）
- `System/`   ：`Delay.c/.h`（**自写**：基于 SysTick 轮询，不占定时器）
- `Hardware/` ：`PWM / Motor / Key / Pendulum / Swing / OLED` 及字库（**OELD 驱动与 6x8 字模均为自写**，非教程代码）
- `User/`      ：`main.c`、`stm32f10x_conf.h`、`stm32f10x_it.c/.h`（**控制逻辑自写**）

打开后直接 **Build**（F7）→ **Download/Debug**（F8）即可。

> **代码来源说明（原创性）**
> - **自写（原创）**：`main.c`（主循环/控制节拍）、`Pendulum.c/.h`（编码器+ADC 合成绝对摆角）、`Swing.c/.h`（能量法泵摆控制器）、`Motor.c/.h`/`PWM.c/.h`/`Key.c/.h`（电机/PWM/按键驱动）、`Delay.c/.h`（SysTick 延时）。
> - **教程版 OLED 驱动**：`Hardware/OLED.c/.h` + `OLED_Data.c/.h` 来自桌面"电赛2026\学习资料\0.96寸OLED显示屏-程序源码"（江协教程），按用户要求直接复用，未自写。
> - **ST 官方芯片 SDK（非"别人项目代码"，等同 C 标准库）**：`Start/`（CMSIS 启动文件 `startup_stm32f10x_md.s`、`system_stm32f10x.c`、`core_cm3.c`）、`Library/`（标准外设库）。这是每个 STM32 Keil 工程都会链接的厂商库，重写它无意义也更易出错，故保留。

> ⚠️ **重要**：工程选项 **不要勾选 Use MicroLIB**。
> 本工程用到 `cosf / fabsf` 等浮点数学函数（能量法控制器），需用 Keil 完整 C 运行库链接；MicroLIB 不含这些函数会导致 **Undefined symbol _cosf / _fabsf** 链接报错。
> 工程文件里该选项已默认关闭（`useUlib=0`），只要你不手动去勾选即可。
>
> 首次打开若提示安装设备包 `Keil.STM32F1xx_DFP`，点安装即可（工程已引用 2.2.0）。

## 三、硬件接线（默认，按你实际改常量）

| 信号 | 引脚 | 说明 |
|------|------|------|
| 电机 PWM | PA0 (TIM2 CH1) | 占空比 0~100 |
| 电机方向 | PB12 / PB13 | AIN1=PB12, AIN2=PB13；正转 PB12=1/PB13=0，反转反之 |
| 臂角编码器 | PA6 / PA7 (TIM3) | 电机编码器，正交输入 |
| 摆杆角度 | PB0 (ADC1_IN8) | 角度传感器电位器 (SENSOR1) |
| OLED(软件I2C) | PB8 / PB9 | 教程版 SSD1306 驱动，地址 0x78 |
| 启动键 K1 | PB10 (上拉) | 按下启动一次 |

> 摆杆绝对角 = `THETA_SIGN × (臂角 + 摆杆相对臂角)`，零位在按 K1 启动时由 `Pendulum_Zero` 采样当前 ADC 值对齐（上电后先把摆杆放垂再按 K1）。
> 若上电无法保证零位，可加一个"归零"步骤（如按键触发 `Pendulum_Zero` 后手动把摆杆放垂再按启动）。

## 四、上板调参（主要就这几个）

`Hardware/Swing.h` / `Swing.c`：

| 参数 | 默认 | 作用 |
|------|------|------|
| `PUMP_PWM` | 70 | 每次踢占空比(0~100). 泵太弱→调大(80~100); 抖得厉害/撞限位→调小(35~50, 博客原值35即可打到倒立) |
| `KICK_MS` | 90 | 每次踢持续(ms). 博客 START_TIME=100, 80~120 均可 |
| `BRAKE_MS` | 35 | 两次踢之间硬制动(ms): 臂反向前先卸动量, 保证绝不单方向转. 30~50 即可 |
| `TURN_THRESH_DEG` | 3.0 | 判定"最高点"的摆角幅度门槛(°). 2~5 都能尽早起泵 |
| `ARM_LIMIT_DEG` | 90.0 | 臂角硬越界保险(°). 机械臂转不到就调小(如70). 有刹车本不会触发 |
| `SHRINK_MARGIN_DEG` / `SHRINK_CYCLES` / `AMP_LEARN_DEG` | 1.5 / 2 / 15.0 | 自动学习泵方向用: 幅度>15°后, 连续2周期峰值缩小超1.5°→翻转. 一般不用动 |
| `TIMEOUT_MS` | 30000 | 超时判失败 |

- **无需方向校准开关**：方案 I 去掉了脆弱的启动标定，泵方向由自动学习得到（屏 `Sign:±1` 可看）。若摆杆起不来，自动学习会在幅度>15°后翻转纠正，用户无需手动翻符号。
- `Pendulum.h` 的 `THETA_SIGN`：若 OLED 显示摆角正负反了，改 `-1`（仅影响显示/相位侧判定，不影响"不转圈"）。

`Pendulum.c` 的 `ARM_PPR`：按电机编码器线数×4 填（例：13 线 → 52）。摆杆角度来自 ADC 电位器，斜率 `PEND_ADC_DEG_PER_LSB` 可按实际行程校准。
